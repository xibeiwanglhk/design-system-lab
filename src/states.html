练习 1 · 组件的四种状态

组件状态矩阵

每个组件都要有 default / hover / pressed / disabled 四种状态。真实交互用 :hover、 :active、:disabled 表达；为了能在一屏里静态检查全部状态，组件同时提供 .is-hover、.is-pressed、.is-disabled 强制状态类。

这个页面同时是"导入 Figma 对照"的样板页：在 Figma 中按同样的 State 变体搭组件，改完令牌后回到这里逐格比对。 回到 信息流页 可以体验真实鼠标交互。

Button 按钮 · 3 变体 × 4 状态

hover / pressed 的差异全部来自变体类里的私有变量（--_btn-bg-hover 等），状态规则只写一遍。

Primary 主要按钮

默认 Default class="btn btn--primary"
悬停 Hover .is-hover / :hover
按下 Pressed .is-pressed / :active
禁用 Disabled disabled 属性
禁用（aria） aria-disabled="true"

Secondary 次要按钮

默认 Default class="btn btn--secondary"
悬停 Hover .is-hover / :hover
按下 Pressed .is-pressed / :active
禁用 Disabled disabled 属性

Ghost 幽灵按钮

默认 Default class="btn btn--ghost"
悬停 Hover .is-hover / :hover
按下 Pressed .is-pressed / :active
禁用 Disabled disabled 属性

Button 尺寸与形态

尺寸来自 --size-control-height-*，危险变体来自语义状态色。
