# 02 · 组件实现：Button 与 FeedCard 的四种状态

> 阶段 2 的目标：**能独立解释并手写"四状态"按钮和卡片，知道每一行为什么这么写。**
> 代码文件：[src/styles/components.css](../src/styles/components.css) · 对照页：[src/states.html](../src/states.html)

---

## 1. 需求矩阵

| 组件 | 变体 | 尺寸 | 状态 |
| --- | --- | --- | --- |
| Button | `primary` / `secondary` / `ghost` / `danger` | `sm` / `md`（默认）/ `lg` | default / hover / pressed / disabled |
| FeedCard | 默认卡片 / `card--interactive`（整卡可点击） | 宽度自适应 | default / hover / pressed / disabled |

两个组件都要同时满足两种使用场景：

1. **真实交互**：用户在浏览器里用鼠标、键盘操作。
2. **静态展示**：状态矩阵页、设计走查、导入 Figma 对照时，需要"不用鼠标也能看到 hover/pressed"。

这就是为什么每套状态要写两遍选择器——但样式值只写一遍（见第 4 节）。

## 2. HTML 结构与语义

### 2.1 Button：优先用原生 `<button>`

```html
<!-- 主要按钮 -->
<button class="btn btn--primary" type="button">提交</button>

<!-- 次要按钮 + 小尺寸 -->
<button class="btn btn--secondary btn--sm" type="button">取消</button>

<!-- 带图标（图标继承文字颜色，用 currentColor） -->
<button class="btn btn--secondary" type="button">
  <svg class="btn__icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" aria-hidden="true">
    <path d="M12 5v14M5 12h14" stroke-linecap="round" />
  </svg>
  新建
</button>

<!-- 导航用链接：样式像按钮，但语义仍是链接 -->
<a class="btn btn--ghost" href="/posts">查看全部</a>

<!-- 禁用：原生 disabled，鼠标、键盘、表单都不会触发 -->
<button class="btn btn--primary" type="button" disabled>已禁用</button>

<!-- 逻辑禁用：元素仍可聚焦/可被读屏读到，但点击被 JS 拦截 -->
<button class="btn btn--danger" type="button" aria-disabled="true">危险操作</button>
```

要点：

- **能用 `<button>` 就不要用 `<div>`**：原生元素自带键盘行为、表单语义、禁用能力。
- 导航用 `<a>` 时不要加 `role="button"`，也不要用 `<a href="#">` 假按钮。
- `type="button"` 防止按钮在 `<form>` 里意外提交。
- 装饰性图标加 `aria-hidden="true"`；只有图标的按钮必须给 `aria-label`。

### 2.2 FeedCard：`<article>` + 三段结构

```html
<article class="card card--interactive" tabindex="0"
         data-title="标题" aria-label="打开卡片：标题">
  <header class="card__header">
    <span class="avatar" aria-hidden="true">林</span>
    <div class="card__meta">
      <span class="card__author">林小满</span>
      <span class="card__time">3 小时前 · 设计</span>
    </div>
    <button class="btn btn--ghost btn--sm card__more" type="button" aria-label="更多操作">⋯</button>
  </header>

  <div class="card__body">
    <h3 class="card__title">标题</h3>
    <p class="card__text">正文……</p>
    <div class="card__media" aria-hidden="true">图片占位</div>
    <ul class="card__tags">
      <li class="tag">#设计令牌</li>
    </ul>
  </div>

  <footer class="card__footer">
    <span class="card__stats">♡ 128 · 💬 32</span>
    <div class="card__actions">
      <button class="btn btn--ghost btn--sm" type="button">收藏</button>
      <button class="btn btn--primary btn--sm" type="button">阅读全文</button>
    </div>
  </footer>
</article>
```

要点：

- `<article>` 表示一条独立内容（信息流里的"一条"），`<header>` 放作者信息，`<footer>` 放操作。
- 整卡可点击时：容器可聚焦（`tabindex="0"`）+ 键盘处理（Enter/Space）+ 可读名称（`aria-label`）。
- 卡片内部还有按钮时，**点击事件要判断来源**，否则点"收藏"会同时触发整卡打开（见 `src/app.js`）。
- 禁用卡片用 `aria-disabled="true"`，保留内容与可读性。

## 3. CSS 分层：为什么组件只吃"语义令牌"

| 文件 | 职责 | 允许使用 |
| --- | --- | --- |
| `tokens.css` | 生成物：CSS 变量 | — |
| `base.css` | reset、版式、页面布局、文档页辅助样式 | 语义令牌 + 少量 core（`--space-8` 等布局间距） |
| `components.css` | Button / Tag / Avatar / Card | **只用语义令牌** |

组件里出现这些，就说明分层破了：

```css
/* ❌ 写死值：换品牌色、换主题都不会生效 */
.btn--primary { background: #2563eb; border-radius: 10px; }

/* ❌ 用 core 色板：语义上"品牌色"换了，按钮不跟随 */
.btn--primary { background: var(--color-blue-600); }

/* ✅ 只用语义令牌 */
.btn--primary {
  --_btn-bg: var(--color-brand-bg);
  border-radius: var(--radius-control);
}
```

## 4. 四种状态的三种写法（重点）

### 写法一：四个独立 class（不推荐）

```css
.btn-default { background: #2563eb; }
.btn-hover   { background: #1d4ed8; }
.btn-pressed { background: #1e40af; }
.btn-disabled { background: #f1f5f9; }
```

问题：状态之间会**互相覆盖**（同时有 hover 和 pressed 时谁赢？），每加一个变体就要多写 4 份颜色，很快漂移。

### 写法二：真实伪类各写一份（能跑，但重复）

```css
.btn--primary { background: var(--color-brand-bg); }
.btn--primary:hover { background: var(--color-brand-bg-hover); }
.btn--primary:active { background: var(--color-brand-bg-active); }
/* 再加 secondary、ghost……每个变体重复三遍 */
```

### 写法三：私有变量收敛 + 状态规则只写一次（本项目采用）

**第一步**：基础类只消费"私有变量"，不直接写颜色。

```css
.btn {
  --_btn-bg: transparent;
  --_btn-bg-hover: transparent;
  --_btn-bg-active: transparent;
  --_btn-fg: var(--color-text-primary);
  --_btn-border: transparent;

  background-color: var(--_btn-bg);
  color: var(--_btn-fg);
  border: 1px solid var(--_btn-border);
}
```

**第二步**：变体类只负责"把私有变量映射到语义令牌"。

```css
.btn--primary {
  --_btn-bg: var(--color-brand-bg);
  --_btn-bg-hover: var(--color-brand-bg-hover);
  --_btn-bg-active: var(--color-brand-bg-active);
  --_btn-fg: var(--color-text-on-brand);
  /* 边框保持 transparent，不用写 */
}
```

**第三步**：状态规则对所有变体只写一遍。

```css
/* 真实 hover（只在支持 hover 的设备上启用） */
@media (hover: hover) and (pointer: fine) {
  .btn:not(:disabled):not([aria-disabled="true"]):not(.is-disabled):hover {
    background-color: var(--_btn-bg-hover);
    color: var(--_btn-fg-hover);
    border-color: var(--_btn-border-hover);
  }
}

/* 真实按下 */
.btn:not(:disabled):not([aria-disabled="true"]):not(.is-disabled):active {
  background-color: var(--_btn-bg-active);
  color: var(--_btn-fg-active);
  border-color: var(--_btn-border-active);
  transform: translateY(1px) scale(0.99);
}

/* 强制 hover（状态矩阵 / 截图 / Figma 对照） */
.btn.is-hover:not(:disabled):not([aria-disabled="true"]):not(.is-disabled) {
  background-color: var(--_btn-bg-hover);
  color: var(--_btn-fg-hover);
  border-color: var(--_btn-border-hover);
}

/* 强制 pressed */
.btn.is-pressed:not(:disabled):not([aria-disabled="true"]):not(.is-disabled) {
  background-color: var(--_btn-bg-active);
  color: var(--_btn-fg-active);
  border-color: var(--_btn-border-active);
  transform: translateY(1px) scale(0.99);
}

/* 禁用：必须写在最后 */
.btn:disabled,
.btn.is-disabled,
.btn[aria-disabled="true"] {
  background-color: var(--color-disabled-bg);
  border-color: var(--color-disabled-border);
  color: var(--color-disabled-text);
  box-shadow: none;
  transform: none;
  cursor: not-allowed;
}
```

**收益**：加一个 `btn--success` 变体，只需要 4~6 行变量映射，四种状态自动拥有。

### 为什么 disabled 必须写在最后？

CSS 同优先级时"后写的赢"。真实 hover 选择器带了 `:not(:disabled)` 等守卫，理论上不会命中禁用按钮；但 `.is-hover`、`.is-pressed` 这类强制类和 `[aria-disabled="true"]` 是平级的，**把禁用规则放最后**才能保证"任何强制状态 + 禁用"都显示为禁用。

另外注意 `:not(:disabled):not([aria-disabled="true"])` 的守卫是必须的：`<button disabled>` 在部分浏览器里仍会匹配 `:hover`，不加守卫会出现"禁用按钮 hover 还变色"。

## 5. Button 逐段讲解

### 5.1 基础布局

```css
.btn {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  gap: var(--space-stack-sm);
  min-height: var(--size-control-height-md);   /* 40px，内容多时自动变高 */
  padding-inline: var(--space-stack-lg);       /* 水平 16px */
  border: 1px solid var(--_btn-border);        /* 永远留 1px 边框，避免 hover 抖动 */
  border-radius: var(--radius-control);
  line-height: 1;
  white-space: nowrap;
  cursor: pointer;
  user-select: none;
  -webkit-tap-highlight-color: transparent;
  transition: background-color var(--motion-duration-fast) var(--motion-easing),
              border-color   var(--motion-duration-fast) var(--motion-easing),
              color          var(--motion-duration-fast) var(--motion-easing),
              transform      var(--motion-duration-fast) var(--motion-easing);
}
```

细节解释：

- `inline-flex + center`：文字和图标天然垂直居中，图标不会基线错位。
- `min-height` 而不是 `height`：中文/emoji/换行时按钮能自适应。
- `border: 1px solid transparent`：secondary 按钮 hover 时只换颜色，不改变尺寸，避免 1px 抖动。
- `transition` 同时包含 `transform`：按下时的 `translateY(1px) scale(0.99)` 才有回弹感。
- `-webkit-tap-highlight-color: transparent`：去掉移动端点击时的灰色高亮块。

### 5.2 变体映射表

| 变体 | 背景 | 文字 | 边框 | hover 背景 | active 背景 |
| --- | --- | --- | --- | --- | --- |
| `btn--primary` | `--color-brand-bg` | `--color-text-on-brand` | 透明 | `--color-brand-bg-hover` | `--color-brand-bg-active` |
| `btn--secondary` | `--color-bg-surface` | `--color-text-primary` | `--color-border-default` | `--color-bg-surface-hover` | `--color-bg-surface-active` |
| `btn--ghost` | 透明 | `--color-text-secondary` | 透明 | `--color-bg-surface-hover` | `--color-bg-surface-active` |
| `btn--danger` | `--color-status-danger` | `--color-text-on-brand` | 透明 | `--color-status-danger-hover` | `--color-status-danger-active` |

### 5.3 尺寸与形态

| class | 高度 | 水平内边距 | 字号 |
| --- | --- | --- | --- |
| `btn--sm` | 32px | 12px | 14px |
| 默认 | 40px | 16px | 16px |
| `btn--lg` | 48px | 20px | 16px |
| `btn--block` | 100% 宽 | 同尺寸 | 同尺寸 |

### 5.4 焦点环（键盘可访问性）

```css
.btn:focus-visible {
  outline: 2px solid var(--color-border-focus);
  outline-offset: 2px;
}
```

- 用 `:focus-visible` 而不是 `:focus`：鼠标点击不出现焦点环，键盘 Tab 才出现。
- 用 `outline` 而不是 `box-shadow`：不占布局、不引起重绘抖动、在高对比度模式下更可靠。

### 5.5 `disabled` 与 `aria-disabled` 的区别

| | `disabled` 属性 | `aria-disabled="true"` |
| --- | --- | --- |
| 可否聚焦 | 不能 | 能（需要 JS 拦截） |
| 是否触发 click | 不触发 | 触发，需要自己 `preventDefault` |
| 读屏软件 | 朗读"不可用" | 朗读"不可用"（需配合 `aria-*`） |
| 适用 | 表单里真的不能提交 | 仍需要解释原因/仍要能被发现 |

本项目的做法：

- 原生禁用 → `disabled` 属性 + CSS `:disabled`。
- 逻辑禁用 → `aria-disabled="true"` + CSS 属性选择器 + JS 拦截（`app.js` 里的 `tryOpenCard` / 点击委托）。

## 6. FeedCard 逐段讲解

### 6.1 容器与状态变量

```css
.card {
  --_card-bg: var(--color-bg-surface);
  --_card-border: var(--color-border-subtle);
  --_card-shadow: var(--shadow-card);

  display: flex;
  flex-direction: column;
  padding: var(--space-card-padding);
  border: 1px solid var(--_card-border);
  border-radius: var(--radius-surface);
  background-color: var(--_card-bg);
  box-shadow: var(--_card-shadow);
  transition:
    background-color var(--motion-duration) var(--motion-easing),
    border-color var(--motion-duration) var(--motion-easing),
    box-shadow var(--motion-duration) var(--motion-easing),
    transform var(--motion-duration) var(--motion-easing);
}

/* 只有加了 card--interactive，整卡才能点，才需要 hover 手型 */
.card--interactive { cursor: pointer; }

/* 真实 hover：上浮 2px + 阴影加深 + 边框变强 */
@media (hover: hover) and (pointer: fine) {
  .card--interactive:not(.is-disabled):not([aria-disabled="true"]):hover {
    --_card-border: var(--color-border-default);
    --_card-shadow: var(--shadow-card-hover);
    transform: translateY(-2px);
  }
}

/* 真实按下：回落 + 轻微缩小 */
.card--interactive:not(.is-disabled):not([aria-disabled="true"]):active {
  --_card-shadow: var(--shadow-card);
  transform: translateY(0) scale(0.998);
}
```

和 Button 一样，状态规则消费 `--_card-*` 私有变量，强制状态类（`.is-hover` / `.is-pressed`）用同一组值。

### 6.2 禁用态

```css
.card.is-disabled,
.card[aria-disabled="true"] {
  background-color: var(--color-disabled-bg);
  border-color: var(--color-disabled-border);
  box-shadow: none;
  transform: none;
  cursor: not-allowed;
}

/* 内部文字降级 */
.card[aria-disabled="true"] :is(.card__author, .card__title, .card__time, .card__text) {
  color: var(--color-disabled-text);
}

/* 内部按钮：不可点、不可聚焦、统一禁用外观 */
.card[aria-disabled="true"] :is(button, a) {
  pointer-events: none;
  background-color: var(--color-disabled-bg);
  border-color: var(--color-disabled-border);
  color: var(--color-disabled-text);
  box-shadow: none;
  transform: none;
}
```

为什么要处理内部按钮？因为"卡片禁用"是**整块内容不可操作**，如果内部"阅读全文"还是亮蓝色，用户会以为可以点。

### 6.3 内部元素

| 类名 | 作用 | 关键令牌 |
| --- | --- | --- |
| `.card__header` | 头像 + 作者 + 更多按钮 | `--space-stack-md` |
| `.avatar` | 圆形头像（40/32） | `--size-avatar`、`--radius-pill`、`--color-brand-muted` |
| `.card__author` / `.card__time` | 作者/时间 | `--font-size-meta`、`--color-text-primary/muted` |
| `.card__more` | 右上角更多按钮 | 复用 `btn btn--ghost btn--sm` |
| `.card__title` | 标题 | `--font-size-title`、`--font-weight-semibold` |
| `.card__text` | 正文，最多 3 行（`-webkit-line-clamp`） | `--font-size-body`、`--color-text-secondary` |
| `.card__media` | 媒体区（16:7 占位） | `--radius-tag`、`--color-brand-subtle` |
| `.card__tags` | 标签行 | `.tag` |
| `.card__footer` / `.card__actions` | 底部统计与操作按钮 | `--space-*`、`--color-border-subtle` |

> `-webkit-line-clamp: 3` 是限制正文行数的常用写法（配合 `display: -webkit-box`）。虽然带前缀，但主流浏览器都支持。

## 7. 状态矩阵页（states.html）怎么用

打开 <http://localhost:4173/states.html>，它包含：

1. **Button 3 变体 × 4 状态** 的并排网格 —— 每格标注了"真实交互选择器"和"强制类"。
2. **尺寸/形态展示** —— sm/md/lg、danger、带图标、链接按钮、整行按钮。
3. **FeedCard 4 状态** —— 同一张卡片的四个版本，方便逐像素比对。
4. **设计令牌总览** —— 色块 + CSS 变量名 + Figma 变量名的三方对照。
5. **CSS ↔ Figma 状态命名对照表** —— 搭 Figma 组件时照着命名。

怎么用它做设计走查：

1. 打开页面，再打开对应的 Figma 文件（阶段 4 生成的组件集）。
2. 逐行对比：颜色、圆角、内边距、字号、阴影。
3. 切换暗色再对比一遍。
4. 不一致时先查令牌（`tokens.json`），再查组件 CSS，最后才查 Figma 手动改的值。

- [ ] 暗色模式下所有文字仍可读

## 9. 选做练习（推荐至少做一个）

### 练习 1：加一个成功按钮 `btn--success`

要求：

1. 在 `tokens.json` 增加 `semantic.color.status.success-hover`（引用 `color.green.700`）和 `success-active`（可复用 `color.green.700`，也可以加更深的 `green.800`）。
2. 增加 `.btn--success` 变体，只映射 4~6 个私有变量。
3. 在 `states.html` 增加一行成功按钮的四状态。

验收：不需要改任何状态规则，四状态自动生效；暗色下协调（暗色沿用同一绿色，或你在 `dark` 里覆盖）。

### 练习 2：紧凑卡片 `card--compact`

要求：

- 内边距从 20px 降到 12px；
- 隐藏 `.card__media`；
- 标题字号降为 `--font-size-body`；
- 仍然只用语义令牌。

验收：在 `index.html` 里用 `<article class="card card--compact">` 能正常渲染，且状态矩阵不受影响。

### 练习 3：给按钮加 loading 状态（挑战）

要求：

- `.btn.is-loading`：显示 spinner（CSS 动画）、`pointer-events: none`、`aria-busy="true"`；
- 不改变按钮宽度（防止布局跳动）；
- 保留原文字但透明（用 `color: transparent` 或伪元素覆盖）。

提示：spinner 可以用 `border` + `border-top-color` 旋转实现；`prefers-reduced-motion` 下改为静态圆点。
